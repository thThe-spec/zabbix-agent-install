# zabbix-agent-install
Zabbix 6.4 Agent 2 Installation Script in Ubuntu 22.04

1. Create a .sh file (ex: install.sh)
2. Copy and paste the content of the script (zabbix-agent-install.sh)
3. Don't forget to change the "Server=" and "ServerActive=" parameters with your Zabbix Server IP
4. Exit and run the .sh file
